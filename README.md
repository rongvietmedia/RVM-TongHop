# RVM Tổng Hợp - Phần mềm tổng hợp video tự động

Phần mềm desktop Windows giúp tự động tải clip Creative Commons, AI lời bình, TTS giọng đọc, ghép video Shorts — tất cả trong một.

## Tính năng chính

- Tìm và tải video Creative Commons từ YouTube tự động
- AI phân tích, chấm điểm khoảnh khắc hay
- Tạo lời bình tự động bằng GPT-4o-mini
- Text-to-Speech đa ngôn ngữ (ElevenLabs, ai84.pro)
- Ghép video Shorts với phụ đề ASS
- Phát hiện trùng lặp bằng dHash
- Quản lý bản quyền offline (Ed25519)

## Cài đặt

Tải file `.exe` từ [Releases](https://github.com/rongvietmedia/RVM-TongHop/releases) và cài đặt.
